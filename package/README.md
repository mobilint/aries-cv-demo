# ARIES CV Demo Package

This package is the deployable source bundle for the unified CLI-selected CV demo.

## Package Contents

The archive generated by `package/package.sh` contains:

- `src/demo/` source code
- `assets/` demo manifests, layouts, and placeholder asset directories
- `download.sh` and `download.bat` for downloading videos and model files from Hugging Face Buckets
- `Makefile` for package-local builds
- bundled `qbruntime` and `yaml-cpp` headers and libraries

## Requirements

- `g++` or another C++17-compatible compiler
- `make`
- `pkg-config`
- `libopencv-dev`
- Mobilint driver and runtime environment
- `uv` for downloading Hugging Face Bucket assets

## Download Assets

Large `.mxq` model files and `.mp4` sample videos are downloaded after extraction instead of being bundled in the archive:

```bash
./download.sh
```

On Windows, use:

```bat
download.bat
```

Default buckets:

- `hf://buckets/mobilint/aries-weapon-detection-demo-assets`
- `hf://buckets/mobilint/aries-fire-detection-demo-assets`

The downloader fills:

- `assets/weapon/mxq/` and `assets/weapon/video/`
- `assets/fire/mxq/` and `assets/fire/video/`

If the buckets require authentication, log in with the Hugging Face CLI or configure credentials outside this package before running the downloader.

## How to Build

Inside the extracted package directory:

```bash
make -j"$(nproc)"
cd build
./demo
```

The package `Makefile` builds the executable at `build/demo`.

## Runtime Configuration

The packaged application reads:

- `assets/weapon/config/demo.yaml`
- `assets/fire/config/demo.yaml`

When running `build/demo`, keep the package directory layout intact. The manifests resolve their own asset/model paths relative to the manifest file location.

## Demo Manifest

Edit `assets/<demo-name>/config/demo.yaml`.
`demo.yaml` points to the split setting files for layout, feeders, and models.

Key manifest fields:

- `layout_setting`
- `feeder_setting`
- `model_setting`
- `ui.overlay_style`

Current pipeline types:

- `yolo26_det`
- `yolo11_det`
- `yolo_anchorless_det`
